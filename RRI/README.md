
## libGDX Interaktiven prikaz podatkov

      - prikaz območja, povezanega z našo temo 
        - zemljevid lahko ustvarimo na pljuben način

    - podatki
      - vizualizacija podatkov
        - pričakujejo se animacije (yippie)
        - zemljevid mora biti interaktiven
    - dodatne (neobvezne) funkcionalnosti
