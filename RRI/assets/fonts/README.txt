FONTS FOR MBUSIIMAP
==================

For the best visual experience, download the Inter font family:

1. Go to: https://fonts.google.com/specimen/Inter
2. Click "Download family"
3. Extract and copy these files here:
   - Inter-Regular.ttf
   - Inter-Bold.ttf

The application will fall back to default fonts if these are not present.

Inter is a free, open-source font designed for optimal screen readability.
